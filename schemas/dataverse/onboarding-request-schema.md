# Onboarding Request Schema

Generated on: 2026-07-24

This additive schema defines the Dataverse queue used by the User & Access onboarding workflow. The portal creates an `OnboardingRequest` row through Power Pages `/_api`. A Dataverse-triggered automation processes the row and writes contact, invitation, assignment, audit, and result status.

## Portal Permission Intent

Power Pages Platform Administrator can create and read onboarding requests. Ordinary Data Collector users have no access to this table. Server-side automation owns processing updates.

## Security

Do not store bearer tokens, anti-forgery tokens, passwords, connector credentials, client secrets, or credential-bearing URLs in this table.

Invitation code fields are allowed only for the approved mailbox manual fallback path because `mp_onboardingrequest` is administrator-only. They must be shown only to Platform Administrators, treated as single-use onboarding material, and paired with an expiry date. CRDB administrators should communicate manual codes only through an approved internal channel.
