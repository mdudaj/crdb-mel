# Research-Driven CRDB SFU MEL Shell Options

These mockups translate the preferred dark material dashboard direction into CRDB/SFU MEL shell options.

Common shell rules:
- CRDB Bank logo at the top of the left nav.
- System name: MEL Tool.
- Segmented navigation groups: Core Modules, Field Operations, Results & Learning, Admin.
- Bottom organization switcher: Sustainable Finance Unit / Head Office with dropdown affordance.
- Elevated surface cards for rows and data blocks.
- Right-side MEL AI Assistant and Quick Actions panel.
- CRDB palette: deep navy, CRDB green, operational yellow, blue/teal/orange/red semantic states.

Options:
1. `mel-rd-01-sfu-command-centre` - recommended future master shell.
2. `mel-rd-02-programme-operations` - best immediate TACATDP/SFU alignment.
3. `mel-rd-03-results-framework-studio` - indicators, logframe, and reporting design direction.
4. `mel-rd-04-evidence-assurance` - compliance, safeguards, verification, and audit direction.
5. `mel-rd-05-field-beneficiary-monitoring` - beneficiary/field work and geo-monitoring direction.

Research influences:
- ActivityInfo: centralized MEL data collection, validation/relevance rules, maps, beneficiary progress, offline sync, role permissions, reporting integrations.
- DevResults: user dashboards, indicator reports, graph/matrix/map/pie views, MultiMatrix, performance overview, indicator definitions and disaggregation.
- DHIS2: indicator builder, pivot tables, line lists, maps/GIS, dashboards, tracker/event records, automatic aggregation from individual records to reporting.
- Mathematica MEL: logic models and evaluation matrices linking questions, indicators, data sources, and analytic methods.
