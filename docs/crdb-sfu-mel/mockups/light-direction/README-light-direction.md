# Light CRDB SFU MEL Shell Direction

This set is the recommended design direction after reviewing the dark dashboard inspiration.
The dark reference is used for density, elevated card grouping, right-side action panels, and operational composition only. The default platform theme remains a light CRDB banking operations interface.

Shared decisions:
- Light workspace with elevated white cards.
- Deep navy left navigation.
- CRDB green for primary actions and success states.
- Amber/yellow for warnings and active markers only.
- Red for risk/failure only.
- Segmented side navigation: Current Work, MEL Platform, Administration.
- Bottom SFU/branch selector: Sustainable Finance Unit / Head Office.
- Right operational rail: Quick Actions, Attention, future MEL Assistant.
- Dashboard cards sit on top of MEL system modules: field data, indicators, evidence, reporting, learning, user/access, and activity.

Options:
1. `mel-light-01-tacatdp-command-centre` - recommended immediate TACATDP shell alignment.
2. `mel-light-02-sfu-portfolio-overview` - future SFU portfolio dashboard.
3. `mel-light-03-field-monitoring` - field and beneficiary operations.
4. `mel-light-04-results-learning` - indicators, results framework, and learning products.
5. `mel-light-05-evidence-assurance` - evidence, safeguards, verification, and audit.
