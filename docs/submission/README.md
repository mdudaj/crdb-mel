# Sustainable Finance MEL Platform submission pack

Start here when reviewing the prototype documentation.

## What this pack covers

This pack documents the Sustainable Finance MEL Platform prototype and the proposed scalable product direction.

The current prototype uses TACATDP monitoring as the proof-of-concept use case. The active prototype architecture is Power Pages plus Dataverse. The future product should support a broader Sustainable Finance Unit operating scope and should go through architecture review before production rollout.

## Key boundaries

- TACATDP is the proof-of-concept use case, not the full platform boundary.
- Power Pages plus Dataverse is the current prototype architecture.
- Power BI is future analytics scope unless it is connected and verified.
- The production platform should not inherit prototype technology choices without architecture review.
- Submission docs use Microsoft Writing Style Guide principles: clear, concise, user-focused, active, and accessible.
