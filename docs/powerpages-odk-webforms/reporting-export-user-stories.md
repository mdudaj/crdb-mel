# Reporting, Export, and Power BI User Stories

- As a monitoring user, I want to view submitted records in a table so that I can quickly inspect collected data without opening every form.
- As a monitoring user, I want to search and filter submissions so that I can focus on a district, submitter, date period, review state, or form version.
- As a reviewer, I want to open a record detail view so that I can inspect metadata and answers before deciding whether a record needs follow-up.
- As a data manager, I want to create a named export so that the same filtered dataset can be downloaded again without rebuilding settings.
- As a data manager, I want XLSX exports to include repeat groups as separate sheets so that roster/repeat data is not lost.
- As a reporting analyst, I want Power BI to connect to Dataverse reporting tables so that dashboards refresh from governed data rather than local files.
- As an administrator, I want reporting projections to be rebuildable from canonical submissions so that derived data can be corrected after schema or projection fixes.
- As a security owner, I want exports and Power BI access to use Dataverse permissions so that private submissions are not exposed through anonymous links.
